# Week 5: automatic differentiation and checkpointing

Three pieces of coursework in one folder:

1. **Part 1 (Python/JAX)** — hand-written forward/reverse AD of the Lennard-Jones
   pair energy, jaxpr graphs, and the forward-vs-reverse cost of a cluster
   energy gradient.
2. **Part 2 (Rust)** — `seismic`, a CLI that simulates damped acoustic waves
   (forward mode) on the reflector experiment.
3. **Parts 3–4 (Rust + Enzyme)** — the same timestep differentiated by Enzyme:
   `born` (chained JVPs) and `adjoint` (chained VJPs, full history or Treeverse
   checkpointing), verified by the transpose identity and applied to Marmousi.

Notes:

- `inputs/`, `*.npy`, `target/`, `.venv/` are not in git; every artifact is
  regenerated by the commands above.
- **Never run Marmousi with `--storage full`**: one shot would keep 1201
  states ≈ 4.16 GB. Treeverse with 5 checkpoints needs 6 states.
- The Enzyme kernel lives in `seismic/src/kernel.rs`, compiled separately by
  `seismic/build.rs` with `-Zautodiff=Enable`; the rest of the crate is
  ordinary Rust (see `.pi/skills/enzyme-setup/SKILL.md`).

## Why the image is not the perturbation

The derivative itself is exact to machine precision (the transpose identity
holds to 4e-16), but migration inverts only what the data can see. The source
wavelet has a finite bandwidth, and the nine shots / 91 receivers illuminate
the model unevenly, so JᵀJ is a band-limited, illumination-weighted blur of
the model rather than the identity. RTM therefore recovers *where* the
reflector is — the row-L2 profile peaks within one grid cell of the true
depth — but not its amplitude or its thin width.

## Final-verification evidence

- *A restart state contains two fields*: `wave::State { um, u }` holds
  `(u^{n-1}, u^n)` — everything the timestep needs; one state is
  `2·nx·nz·8` bytes.
- *One local Enzyme derivative call per reverse step*:
  `enzyme::step_vjp` receives the saved state and the output adjoint and
  returns `(d_um, d_u, d_c)`; the surrounding Rust loop chains them (and adds
  the state-rotation adjoint `λ_new = (dum, du + λ_old.um)`). The dot-product
  identity for one step is tested in `seismic/tests/enzyme.rs`.
- *Replay does not change the accumulated image*:
  `seismic/tests/modes.rs::treeverse_matches_full_history_bitwise` compares
  the checkpointed image to the full-history image element by element
  (bitwise), and the reflector runs report relative L2 error 0.
