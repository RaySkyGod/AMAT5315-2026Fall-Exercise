# Week 4 — Continuum fluid dynamics: the `field` / `fluid` spectral solver

A Rust crate with the time integrators of Part 1 (forward Euler, explicit
midpoint, classical RK4, and an equal-weights RK4) behind one `Integrator`
trait, tested on the periodic advection-diffusion line, and a 2-D
vorticity-equation solver on the periodic square [0, 2π)²: Fourier
pseudospectral derivatives, the two-thirds rule (|kx|, |ky| ≤ ⌊N/3⌋ in the
vorticity and every product), one Poisson solve per stage. Two command
lines: `field` writes an initial field (Taylor-Green or seeded random band,
E(0) = 1/2) as JSON, `fluid` integrates a piped field with `--method
euler|rk2|rk4`, printing `t  E  Z` per snapshot and storing frames; it
stops at the first non-finite energy, prints that line, and exits 1.

The CLI contracts are [`field.design.toml`](field.design.toml) and
[`fluid.design.toml`](fluid.design.toml), copied block by block from the
learning sheet's green panels. The random stream is an in-crate
xoshiro256++ seeded by `--seed`; phases are drawn in an order fixed by the
band alone, so the same seed gives the same field at any grid size `n ≥ 2 k-max + 1`.

Everything the week grades is regenerated by the Python scripts in
`scripts/` (run from there); this README lists every committed file in
`evidence/` beside the command that produces it. `artifacts/` holds the
raw runs, stays untracked, and is rebuilt on demand by the same commands.

## Install

From `week4/`:

```bash
cargo install --path . --quiet   # release build, puts field and fluid on PATH
```

The scripts need Python 3 with `numpy` and `matplotlib`; the script tests
use `pytest`. Rust tests: `cargo test` (26 tests); script tests:
`cd scripts && python3 -m pytest` (11 tests).

## The two pipelines (the values the week uses)

```bash
# Taylor-Green, one decay: E(1) = 0.167580, Z(1) = 0.335160 (six decimals)
field taylor-green --n 64 | fluid --method rk4 --nu 0.1 --dt 0.01 --t-end 1 \
   --every 0.1 --out artifacts/taylor-green > artifacts/taylor-green.tsv

# The seeded random flow the checks and Part 4 use: E 0.500 -> 0.294, Z 6.635 -> 0.923
field random --n 128 --seed 2026 --k-min 2 --k-max 6 | fluid --method rk4 \
   --nu 0.004 --dt 0.01 --t-end 10 --every 0.1 --out artifacts/random \
   > artifacts/random.tsv
```

All further runs (the blow-up scan, the perturbed pairs, the order and
convergence series) are the same two pipelines with different values; the
scripts below run them automatically when their artifacts are missing.

## What the evidence shows (the week's acceptance numbers)

- **Line stability** (`line-stability.png`): the measured |R_RK4| edge sits
  on the analytic curve (axis crossings −2.785, ±2.83i); every mode dot at
  dt = 0.045 lies inside, the outermost at 0.056 outside; the measured
  largest stable step is 0.04939 (sheet: 0.0494); the dt = 0.056 pulse
  erupts into two-grid-point stripes before t = 6.
- **Line accuracy** (`line-accuracy.png`): one lap, max errors 1.8e-5
  (RK4 Fourier, overlaps exact), 0.31 (centred differences, late with a
  wake), 0.21 (Euler, taller); slopes 1.03 / 2.01 / 4.00 / 2.00 — the
  sheet's answer-key values.
- **Derivatives** (`cargo test --test spectral -- --nocapture`): the
  Fourier column reaches roundoff (<1e-13), the finite-difference columns
  are 0.17050/0.04318, 0.25724/0.06487, 0.48534/0.12429, 0.30838/0.07771 —
  the sheet's table, digit for digit.
- **Taylor-Green** (`taylor-green.png`): E(1) = 0.167580, Z(1) = 0.335160;
  final-velocity error 7.04e-7 (< 1e-5 required), against the exact field
  written by `field taylor-green --n 64 --nu 0.1 --t 1`.
- **Limits** (`blowup.png`): diffusive boundary in (0.032, 0.033]
  (predicted 0.0316, within 5%); random advective boundary in (0.036,
  0.038] = 1.9–2.0× the bound 2.83/(U_max·59.4) with U_max = 2.461; Euler
  at dt = 0.01 non-finite at t = 1.3.
- **Sensitivity** (`sensitivity.png`): the perturbed random pair drifts
  apart ×193 by t = 20 (e-folding ~3.8); the Taylor-Green pair agrees to
  six decimals (distance zero in the stored frames) after t ≈ 12.
- **Random decay** (`random.png`): E falls 0.500 → 0.294 (less than half),
  Z falls 6.63 → 0.92 (×7.2): filaments fade first, vortices survive.
- **Order and step choice** (`order.png`, `convergence.*`): slope 4.10 on
  the fluid; self-convergence slope 4.028; Richardson from the dt = 0.02
  and 0.01 fields predicts the errors at all three steps within 2% and
  selects dt = 0.0125 (predicted 3.96e-6, measured 3.89e-6 < 5e-6).

## Known deviation from the answer key

The seeded random field has Z(0) = 6.635 against the sheet's 6.657 (0.3%).
Z(0) is phase-independent for equal amplitudes on the ring 2 ≤ |k| ≤ 6; the
difference traces to a shell-convention detail in the key's band (ours:
all 104 modes with 4 ≤ kx²+ky² ≤ 36, Z = 52/Σk⁻²). E(0) = 0.5 exactly, and
every stability/accuracy acceptance above is unaffected.
